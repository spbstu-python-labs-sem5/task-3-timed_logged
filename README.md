# Задача №3: декоратор `timed_logged`

## Реализовать декоратор, который будет:

- Измерять время выполнения функции в миллисекундах.
- Выводить имя функции, аргументы, результат и время выполнения.
- При ошибке логировать её тип и сообщение, не скрывая исключение.
- Работать с любыми сигнатурами (`*args`, `**kwargs`).
- Сохранять метаданные функции (`__name__`, `__doc__`) через `functools.wraps`.

## Пример использования

```python
from time import sleep

from timed_logged import timed_logged


@timed_logged
def slow_sum(a, b, delay=0.5):
    sleep(delay)
    return a + b


slow_sum(1, 2, delay=0.2)
```

## Решение

- `timed_logged.py` — декоратор, который печатает имя функции, аргументы, результат или исключение и длительность вызова.
- `example.py` — пример `slow_sum`; длительность ожидания вводится в секундах.
- `test_timed_logged.py` — проверки декоратора.

Используются только модули стандартной библиотеки Python; внешние зависимости не нужны.

## Запуск

```bash
python3 example.py
python3 -m unittest
```

При запуске `example.py` введи, например, `0.2`, чтобы функция ждала 0,2 секунды.
